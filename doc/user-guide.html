Accounting Management System

How to use AMS for finance setup, accounting work, approvals, reporting, audit review, and technical administration.

AMS helps different finance teams work in one controlled system. Finance Admins set up the organization and rules, Accountants record transactions, CFOs approve and review results, Auditors inspect history, Admins manage users, and System Admins manage technical integrations.

Application address: http://localhost:9078 Logout path: /users/logout Updated for current implementation

Login And Navigation

Open AMS in your browser. If you are not signed in, you will see the public welcome page. Select the login option and sign in with your organization account.

After login, AMS sends you to the correct workspace based on your assigned group. If you belong to more than one group, your administrator should confirm which group should be used for your daily work.

Your responsibilityWhere AMS takes youWhat you can do there
Admin/admin/usersCreate users, manage groups, enable or disable accounts, send reset emails.
System Admin/system-adminSet up NRS, signing keys, webhooks, storage, API clients, jobs, and integration health.
Finance Admin/financeAdmin/organizationSetupSet up organizations, branches, accounts, periods, modules, taxes, approval rules, and imports.
Accountant/accountant/manualJournalCreate and process journals, invoices, payments, collections, bank reconciliations, expenses, and depreciation imports.
CFO/cfo/approvalsHubApprove journals, manage budgets, review trial balance, and handle financial reports.
Auditor/auditor/auditLogExplorerReview audit logs and security events.
If you see the wrong page after login: contact an Admin to check your group membership. AMS uses your assigned group to decide which screens and actions you can access.

Roles At A Glance

Admin

Manages who can use AMS. This includes creating users, assigning groups, disabling access, and password reset emails.

System Admin

Manages technical settings behind e-invoicing, signing, webhooks, file retention, API clients, and background jobs.

Finance Admin

Sets up the finance foundation: organizations, branches, chart of accounts, fiscal periods, modules, tax rules, and approval rules.

Accountant

Records the daily finance work: journals, invoices, vendor bills, customer collections, payments, expenses, bank reconciliation, and depreciation imports.

CFO

Reviews and approves finance activity, controls budgets, checks trial balance, and manages financial report approval.

Auditor

Reviews evidence of what happened in the system, including business activity, security events, and acknowledgements.

Common Actions

Selecting An Organization

Many pages begin with an organization selector. Choose the organization before adding or viewing records. Lists, forms, reports, and totals usually change after you select an organization.

Saving A Draft

A draft is work that has been entered but is not final. Drafts can normally be edited. Use drafts for invoices, journals, or expenses that need review before submission or posting.

Submitting For Approval

Submit means you are asking another responsible person or rule to review the item. After submission, some fields may stop being editable.

Approving Or Rejecting

Approval allows the item to move forward. Rejection sends the item back or stops it. When rejecting, enter a clear reason so the person who created the item knows what to fix.

Posting

Posting is the accounting step that records the transaction in the general ledger. Posted items affect reports, balances, and audit records. Do not post until the figures and accounts are correct.

Refreshing Lists

Some pages include a refresh button. Use it after another person approves, posts, pays, or changes records that you are viewing.

Admin Guide

Use User Management to control access to AMS.

/admin/users

Create A User

  1. Open User Management.
  2. Enter the person's first name, last name, username, email, and temporary password.
  3. Choose the group that matches the person's job, such as Accountant, CFO, Finance Admin, Auditor, System Admin, or Admin.
  4. Save the user.

Expected result: the user appears in the list and can sign in with the assigned access.

Change A User's Access

  1. Select the user.
  2. Add or remove groups as needed.
  3. Ask the user to sign out and sign in again.

Access changes normally apply on the next login.

Disable, Enable, Reset, Or Delete

Disable a user when access should be paused. Enable restores access. Use reset password email when a user cannot sign in. Delete should be reserved for test users or users that your organization policy allows you to remove.

System Admin Guide

Use Technical Setup to manage integration and platform settings. This section is intended for users responsible for connectivity, security settings, and technical configuration.

/system-admin

NRS Integration

NRS settings control how AMS prepares and submits e-invoice information to the external reporting or clearance service.

  1. Open Technical Setup.
  2. Find NRS Integration.
  3. Turn the integration on or off.
  4. Choose the environment.
  5. Enter provider, base URL, token URL, client ID, scope, and timeouts.
  6. Leave the secret field unchanged if it already shows a masked value and you do not want to replace it.
  7. Save, then use Test to confirm connectivity.

Signing Keys

Signing settings tell AMS which key and algorithm to use when a document or message needs a digital signature.

  1. Enable signing if required.
  2. Enter the algorithm, provider, key alias, and key reference.
  3. Set last rotation and next rotation dates if your policy requires them.
  4. Save and test.

Webhook Platform

Webhook settings control how AMS sends events to other systems.

  1. Enable or disable the platform.
  2. Set the signing algorithm, maximum attempts, timeouts, retry setting, allowed domain pattern, and dead letter retention.
  3. Save the settings.

Storage And Retention

Storage settings control where invoice artifacts and archives are kept and how long they are retained.

  1. Choose whether encryption is enabled.
  2. Enter artifact and archive storage locations.
  3. Enter the encryption key reference if required.
  4. Set retention years, WORM requirement, and immutable archive option.
  5. Save the settings.

API Clients, Jobs, Health, And Audit

Use API Clients to create access records for external systems. Use Background Jobs to review and update scheduled work. Use Integration Health to check whether connected services are healthy. Use Configuration Audit to see who changed technical settings.

Finance Admin Guide

Finance Admin work should usually be completed before daily accounting begins. These settings determine which organizations exist, which accounts can be used, which periods are open, which modules are enabled, and which approvals are required.

Organization Setup

/financeAdmin/organizationSetup

  1. Create the organization.
  2. Enter legal name, registration number, tax ID, country, address, phone, email, and description.
  3. Mark the organization active if users should work with it.
  4. Add branches for the organization.
  5. Refresh and confirm the organization and branches appear correctly.

Chart Of Accounts

/financeAdmin/chartOfAccounts

The chart of accounts is the list of accounts used by journals, invoices, payments, budgets, and reports.

  1. Select an organization.
  2. Create accounts for bank, receivables, payables, tax, retained earnings, revenue, expenses, and depreciation where needed.
  3. Use clear account codes and names.
  4. Set the correct account type and normal balance.
  5. Edit accounts when details change.
  6. Deactivate or delete only accounts that are safe to remove.

Fiscal Configuration

/financeAdmin/fiscalConfiguration

Fiscal settings control accounting years and periods. Periods decide whether transactions can be posted for a date range.

  1. Select the organization.
  2. Create or update fiscal configuration.
  3. Create fiscal periods for the months or quarters users will post into.
  4. Keep periods open while work is still being entered.
  5. Close a period after all reconciliations, approvals, payment runs, and reports are resolved.
  6. Lock a closed period when it should no longer accept changes.

Module Controls

/financeAdmin/moduleControls

Module controls decide which finance features are enabled and how strongly they are controlled.

  1. Create default modules if none exist.
  2. Turn modules on or off.
  3. Set whether approval is required.
  4. Set transaction limits, audit trail, notifications, and notes.
  5. Save and confirm the enabled module list is correct.

Tax Jurisdictions

Tax jurisdictions define tax rules used on customer invoices. Create active tax rules before Accountants create taxable invoices. Inactive tax rules should not be used for new invoices.

Approval Rules

Approval rules decide when submitted work requires review. For example, a high-value manual journal or payment run can be routed for approval before posting or execution.

Bulk Imports

Use bulk import when many branches or accounts need to be loaded at once.

  1. Download the correct template.
  2. Fill in the template carefully.
  3. Upload the file for validation.
  4. Review accepted and rejected rows.
  5. Download the error file if there are rejected rows.
  6. Fix errors and upload again, or confirm the import if the preview is correct.

Accountant Guide

Accountants record daily finance work. Most Accountant pages start with an organization selector. Select the organization first so the page loads the correct customers, vendors, accounts, invoices, and balances.

Manual Journals

/accountant/manualJournal

  1. Create a new journal.
  2. Add a short description and journal date.
  3. Add debit and credit lines.
  4. Confirm total debits equal total credits.
  5. Save the draft.
  6. Submit the journal when ready.
  7. Wait for CFO approval if approval is required.
  8. Post the approved journal.
  9. Review the general ledger lines created by the posting.

Important: posting affects financial reports. Check dates, accounts, and amounts before posting.

Customer Invoices

/accountant/customerInvoicing

  1. Select the organization.
  2. Select an existing customer or create a new customer.
  3. Enter invoice date and due date.
  4. Select the tax jurisdiction if tax applies.
  5. Add invoice lines with description, quantity, price, and account information.
  6. Save the invoice as a draft if it is not ready.
  7. Post the invoice when it is correct.
  8. Generate or download documents such as PDF, JSON, or XML when needed.
  9. Send the invoice and check dispatch history.
  10. Record payment when the customer pays.

When an invoice is posted, AMS increases customer receivables and revenue. When payment is recorded, AMS reduces the outstanding receivable.

Receivables Collections

/accountant/receivablesCollections

  1. Review aged receivables to find overdue customer invoices.
  2. Generate collection cases.
  3. Open a case to review customer and invoice details.
  4. Assign the case to a collector if needed.
  5. Add activities such as calls, emails, or notes.
  6. Send dunning notices when appropriate.
  7. Record a promise to pay when the customer gives a payment date.
  8. Reconcile promises after payments arrive.
  9. Escalate or close the case based on the outcome.
  10. Create and send customer statements when needed.

Purchase Invoices

/accountant/purchaseInvoice

  1. Select the organization.
  2. Select an existing vendor or create a new vendor.
  3. Enter invoice details and line items.
  4. Save as draft while checking the details.
  5. Submit for approval if required.
  6. Post the invoice after approval.
  7. Record payment when the vendor is paid.
  8. Review aged payables to confirm the outstanding balance is correct.

Payables Automation

/accountant/payablesAutomation

Use this page to manage payment schedules, payment runs, supplier statements, and cash needs.

  1. Review payment schedules created from posted purchase invoices.
  2. Approve, hold, reschedule, cancel, submit, or reject schedules as needed.
  3. Create a payment run for approved due schedules.
  4. Submit the run for approval if required.
  5. Approve and execute the run when ready.
  6. Review the cash requirement forecast.
  7. Create supplier statements and auto-match statement lines.
  8. Dispute incorrect supplier statement lines.
  9. Complete the statement once matching and disputes are resolved.

Cash And Bank

/accountant/cashAndBank

  1. Create a bank account and link it to the correct chart account.
  2. Select the bank account.
  3. Import a bank statement file or create a reconciliation.
  4. Review imported statement lines.
  5. Use auto-match to match clear transactions.
  6. Review suggested candidates for unmatched lines.
  7. Manually match or unmatch lines where needed.
  8. Complete the reconciliation when the difference is resolved.

Expenses

Use expenses to record staff or operating costs that are not handled through purchase invoices.

  1. Create the expense.
  2. Add line details and accounts.
  3. Submit for approval if required.
  4. Post after approval.
  5. Record payment.

Budget controls may block expenses when the selected budget is exceeded.

Fixed Assets And Depreciation Journals

/accountant/fixedAssets /accountant/depreciationJournals

Use depreciation journal imports to bring depreciation entries from an external fixed asset process into AMS.

  1. Select the organization.
  2. Enter the source system and batch information.
  3. Upload the depreciation import file or enter the import details provided by your finance process.
  4. Review validation results.
  5. Correct rejected rows before relying on the import.
  6. Review import history for status and totals.

CFO Guide

CFO users review finance activity, approve controlled work, and use reports to confirm that the ledger is accurate.

Approvals Hub

/cfo/approvalsHub

  1. Open the pending approvals list.
  2. Select a submitted journal.
  3. Review description, date, debit lines, credit lines, and totals.
  4. Approve if the entry is correct.
  5. Reject with a clear reason if corrections are needed.

Budget Control

/cfo/budgetControl

  1. Create a budget for the organization and period.
  2. Add budget lines for controlled expense accounts.
  3. Submit and approve the budget.
  4. Activate the budget when it should start controlling spend.
  5. Review dashboard values for approved, consumed, and remaining budget.
  6. Watch warning thresholds and hard stop blocks.

Trial Balance

/cfo/trialBalance

  1. Select the organization and reporting dates.
  2. Generate or refresh the trial balance.
  3. Confirm total debits and total credits are equal.
  4. Create a snapshot when the report should be preserved.
  5. Review previous snapshots when comparing periods.

Financial Reports

/cfo/financialReports

  1. Select the organization and date range.
  2. Generate the report.
  3. Review report lines and totals.
  4. Submit the report for review if needed.
  5. Approve the report when final.
  6. Reject with a reason if it needs correction.

Auditor Guide

Auditors review what happened in AMS. Audit screens are read-focused, except for security event acknowledgement.

Audit Log Explorer

/auditor/auditLogExplorer

  1. Select the organization.
  2. Filter logs by date range or entity when needed.
  3. Review who performed the action, what changed, when it happened, and request details such as IP address or browser information when available.
  4. Use the results as evidence for transaction and control review.

Security Events

/auditor/securityEvents

  1. Select the organization.
  2. Review all or unacknowledged events.
  3. Filter by date or user when investigating an issue.
  4. Acknowledge events after they have been reviewed according to your organization's process.

E-Invoicing And Invoice Documents

AMS includes e-invoicing support for customer invoices. This includes invoice payload preparation, NRS submission tracking, document generation, archive storage, and invoice dispatch history.

What Users Need To Know

  • Customer invoices can have downloadable documents such as PDF, JSON, and XML.
  • Some business-to-business invoices may require NRS clearance before documents can be downloaded.
  • Business-to-consumer invoices can be allowed to download before clearance depending on the invoice type and rules.
  • Missing tax IDs, invalid VAT rates, or missing zero-tax reasons can block payload generation.
  • Every NRS submission keeps metadata and archive details for later review.

Basic E-Invoice Flow

  1. Create and post a customer invoice.
  2. Confirm customer and supplier tax details are complete.
  3. Generate the NRS payload if required.
  4. Submit the invoice for NRS processing.
  5. Review submission status and archive information.
  6. Generate or download invoice documents after clearance rules are satisfied.
  7. Send the invoice and review dispatch history.

External Access And Webhooks

Some organizations connect AMS to other systems. These features are usually managed by System Admins or integration teams.

External Invoice API

The external invoice API lets approved systems search invoices and retrieve invoice details, documents, events, and dispatch history. If an external system cannot find an invoice, first confirm that the invoice exists in AMS and that the external user or API client has the correct access.

Webhooks

Webhooks allow AMS to notify another system when certain events happen.

  1. Create the webhook endpoint.
  2. Use a secure URL unless your environment specifically allows local testing.
  3. Choose authentication settings.
  4. Provide a secret reference for HMAC signing.
  5. Send a test webhook.
  6. Review delivery history.
  7. Update or delete endpoints when they are no longer needed.

Security reminder: secret values should be stored as references. AMS masks secret references in responses so users do not accidentally expose credentials.

Status Guide

Statuses show where an item is in its process. The exact status names can vary by record type, but these meanings are common across AMS.

StatusMeaningWhat to do next
DraftThe item has been started but is not final.Edit, save, or submit when ready.
SubmittedThe item is waiting for review or approval.Wait for the approver or follow up if overdue.
ApprovedThe item passed review.Post, execute, or complete the next step if your role allows it.
RejectedThe item was not accepted.Read the reason, correct the issue, and resubmit if allowed.
PostedThe item has affected the general ledger.Review reports or record payment if applicable.
PaidThe amount has been paid.Confirm the outstanding balance is correct.
ClosedThe work is finished.No further action unless a correction process is required.
LockedThe period or record should no longer accept changes.Contact Finance Admin if a correction is required.

Troubleshooting

I cannot log in

Confirm your username and password. If you still cannot sign in, ask an Admin to check whether your account is enabled and whether a password reset email is needed.

I logged in but see the wrong page

Your group may be missing or incorrect. Ask an Admin to check your group assignment.

I cannot see an organization

Confirm the organization is active. If it is missing, ask a Finance Admin to create or update it.

I cannot post a transaction

Common reasons include an unbalanced journal, missing approval, locked fiscal period, exceeded budget, inactive account, inactive tax rule, missing required field, or unresolved validation error.

A file import failed

Download the error file if available. Correct the row listed in the error, then upload the corrected file again. Use the official template whenever possible.

An invoice document will not download

The invoice may require NRS clearance first, or required tax details may be missing. Review the invoice, customer tax ID, supplier tax ID, tax rate, and NRS submission status.

A webhook test failed

Check that the URL is secure, reachable, allowed by the platform settings, and has the correct authentication or secret reference.
